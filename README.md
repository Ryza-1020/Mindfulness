# FocusLock — עבודה ממוקדת בלי הסחות מהטלפון

אפליקציית Android נייטיב (Kotlin, ‏Jetpack Compose, ‏Material 3) לשימוש אישי. ממשק מלא בעברית ומימין לשמאל. אין שרת, אין חשבון, אין אינטרנט, וכל הנתונים נשמרים במכשיר.

---

## 1. בניית קובץ ה-APK

יש שתי דרכים. אפשר לבחור באחת מהן.

### דרך א׳ — Android Studio (במחשב)

1. מתקינים את [Android Studio](https://developer.android.com/studio) (גרסה Ladybug ומעלה).
2. **File ← Open**, ובוחרים את התיקייה `FocusLock`.
3. מחכים שהסנכרון של Gradle יסתיים. בפעם הראשונה ההורדות לוקחות כמה דקות.
4. בונים: **Build ← Build App Bundle(s) / APK(s) ← Build APK(s)**.
5. הקובץ נוצר בנתיב `app/build/outputs/apk/debug/app-debug.apk`.

אפשר גם לחבר טלפון בכבל (עם "ניפוי באגים ב-USB" מופעל) וללחוץ ▶ Run.

### דרך ב׳ — GitHub, בלי להתקין כלום

1. יוצרים מאגר (repository) פרטי ב-GitHub ומעלים אליו את כל תוכן התיקייה, כולל התיקייה `.github`.
2. בלשונית **Actions** הבנייה מתחילה לבד.
3. אחרי כ-5 דקות, בסיום הריצה, מורידים את **FocusLock-apk** מתחת ל-Artifacts.

> לגרסת release: גם היא חתומה במפתח debug, כדי שאפשר יהיה להתקין אותה ישירות. זה מתאים לשימוש אישי. לפני הפצה צריך להחליף את החתימה במפתח משלך.

## 2. התקנה בטלפון

1. מעבירים את קובץ ה-APK לטלפון (בכבל, ב-Drive או במייל לעצמך).
2. פותחים את הקובץ. כש-Android מבקש, מאשרים "התקנה ממקור לא ידוע" עבור האפליקציה שממנה פתחת אותו.
3. גרסת Android מינימלית: 8.0. מומלץ Android 10 ומעלה.

## 3. הפעלת ההרשאות (פעם אחת)

באפליקציה נכנסים ל**הגדרות** (גלגל השיניים). בראש המסך מופיעות ההרשאות, ולכל אחת יש כפתור "אישור":

| הרשאה | למה צריך אותה | איפה מאשרים |
|---|---|---|
| **גישה ל"נא לא להפריע"** | כדי להשתיק התראות ושיחות, ולהחזיר את המצב הקודם בסיום | נפתחת רשימה, בוחרים FocusLock ומפעילים |
| **התראות** | טיימר בשורת ההתראות ותזכורת לסשן מתוזמן | חלון אישור של Android |
| **התראות ותזכורות (שעון מדויק)** | כדי שסשן מתוזמן יתחיל בדיוק בזמן, ושהסשן יסתיים בדיוק באפס כשהמסך כבוי | מסך מערכת עם מתג (Android 12 ומעלה) |
| **פטור מחיסכון בסוללה** (מומלץ) | ב-Xiaomi, ‏Samsung ו-OnePlus חיסכון אגרסיבי בסוללה עלול לעצור את הטיימר | בוחרים FocusLock ← "ללא הגבלה" |

**הצמדת מסך:** בחלק מהמכשירים צריך להפעיל אותה פעם אחת: **הגדרות ← אבטחה ← הצמדת אפליקציה**. השם משתנה לפי היצרן. באפליקציה יש כפתור שפותח את המסך הזה.

אם לא מאשרים הרשאה, האפליקציה ממשיכה לעבוד. במסך העבודה מוצג בדיוק מה פעיל, למשל: "השתקה לא פעילה – חסרה הרשאה".

## 4. מה בדיוק האפליקציה עושה, ומה Android לא מאפשר

| יכולת | מה קורה בפועל |
|---|---|
| **השתקת התראות** (WhatsApp, ‏Gmail, ‏SMS, רשתות חברתיות וכו׳) | מצב "נא לא להפריע" רשמי. ב-Android 10 ומעלה האפליקציה יוצרת "כלל אוטומטי" משלה, כך שהגדרות "נא לא להפריע" שלך לא נדרסות. התראות לא מצלצלות, לא קופצות ולא מופיעות בשורת הסטטוס |
| **שיחות נכנסות** | **מושתקות, לא נחסמות.** הטלפון מקבל את השיחה, היא לא מצלצלת, ומופיעה כשיחה שלא נענתה. בהגדרות בוחרים מי יעבור בכל זאת: אף אחד, אנשי קשר מועדפים או כל אנשי הקשר, ואפשר גם "מתקשר חוזר" |
| **חריגים** | שעונים מעוררים תמיד פועלים. אפליקציה שהגדרת בהגדרות המכשיר כ"מותר לעקוף נא לא להפריע" ממשיכה להתריע. שיחות חירום אינן נחסמות |
| **הצמדת מסך** (מכשיר רגיל) | בתחילת סשן Android מבקש לאשר הצמדה. במצב מוצמד אי אפשר לפתוח אפליקציות אחרות, את מסך הבית או את ההתראות. **היציאה תמיד אפשרית:** בניווט במחוות מחליקים למעלה ומחזיקים, ובניווט בכפתורים לוחצים יחד לחיצה ארוכה על "חזרה" ו"סקירה". אם יצאת מההצמדה, מופיע במסך הטיימר כפתור "הצמד מסך" |
| **נעילה מנוהלת (Lock Task)** | רק במכשיר שהוגדר ידנית כמכשיר מנוהל (ראו סעיף 6). אז אין חלון אישור, והיציאה היחידה היא דרך האפליקציה: "השהיה" ואז "סיום מוקדם". תפריט הכיבוי (וחיוג חירום) נשאר זמין |
| **פתיחה אוטומטית של סשן מתוזמן** | Android לא מאפשר לאפליקציה לפתוח מסך מלא מהרקע. בזמן שנקבע הטיימר וההשתקה מתחילים, ומופיעה התראה שפותחת את מסך הטיימר. אם מכבים את "התחלה אוטומטית", מופיעה התראה עם כפתור "התחל סשן" |

אין שימוש ב-Root, ב-Accessibility Service, בחלונות שכבה (overlay) או בעקיפת הגנות כלשהן.

## 5. איך הטיימר נשאר מדויק

- הממשק לא סופר שניות. בכל ציור הזמן שנותר מחושב מחדש מתוך חותמות זמן שנשמרו בדיסק.
- המדידה נעשית עם `elapsedRealtime`, שעון רציף שממשיך לרוץ כשהמסך כבוי ולא מושפע משינוי שעה או אזור זמן.
- בהפעלה מחדש של המכשיר, הזמן שבו המכשיר היה כבוי נמדד לפי שעון הקיר (עם תקרת בטיחות של 24 שעות). אחר כך הסשן ממשיך מהנקודה הנכונה.
- מצב הסשן נשמר כל 15 שניות. התראה קבועה (Foreground Service) שומרת את התהליך חי, ושעון מעורר של המערכת מסיים את הסשן באפס גם אם Android סגר את האפליקציה.
- **השהיה** עוצרת רק את הטיימר. הגבלות המכשיר (השתקה והצמדה) נשמרות כברירת מחדל. במסך ההשהיה יש מתג שמשחרר את ההשתקה עד שממשיכים.

## 6. מצב נעילה מתקדם (מכשיר ייעודי בלבד)

> ⚠️ **לא למכשיר האישי שלך.** כדי להגדיר אפליקציה כ"מנהלת המכשיר" (Device Owner) צריך מכשיר בלי חשבונות, בדרך כלל אחרי איפוס להגדרות יצרן. מתאים לטלפון או טאבלט ישן שמשמש רק לעבודה.

1. מאפסים את המכשיר להגדרות יצרן, ומדלגים על הוספת חשבון Google.
2. מתקינים את FocusLock ומפעילים "ניפוי באגים ב-USB".
3. מריצים מהמחשב:
   ```
   adb shell dpm set-device-owner com.focuslock.app/.block.FocusDeviceAdminReceiver
   ```
4. פותחים את FocusLock. בהגדרות יופיע "מכשיר מנוהל: נעילה מלאה זמינה". מעכשיו כל סשן נועל את המכשיר בלי חלון אישור.
5. **ביטול:** הגדרות ← "הסרת FocusLock מניהול המכשיר".

## 8. מבנה הקוד

```
app/src/main/java/com/focuslock/app/
├── FocusLockApp.kt          // אתחול + AppContainer (תלויות)
├── core/                    // לוגיקה טהורה ונבדקת: TimerMath, ScheduleCalculator, StatsCalculator
├── data/                    // Room (סשנים, תזמונים), DataStore (הגדרות), ActiveSessionStore (מצב סשן)
├── session/                 // SessionManager (מקור האמת), FocusSessionService, שעון סיום, התראות
├── block/                   // DistractionController ("נא לא להפריע"), LockController (הצמדה / Lock Task)
├── schedule/                // תזמון ב-AlarmManager, מקלטי אתחול ושינוי שעה
└── ui/                      // Compose: בית, עבודה פעילה, תזמון, נתונים, הגדרות (MVVM)
```

למה AlarmManager ולא WorkManager: WorkManager לא מבטיח התחלה בשעה מדויקת. כשאין הרשאת שעון מדויק, האפליקציה עוברת לחלון גמיש של 5 דקות ומציינת זאת.
